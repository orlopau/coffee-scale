Open **Settings** from the list of modes.

{{< screen name="settings_last" caption="The last settings in the list" >}}

- **Turn** to a setting and **click** to change it.
- **Turn** to change the value, then **click** to save it, or **long-press** to leave it as it was.
- **Long-press** in the list to leave the settings.

{{< screen name="settings_value_up" caption="Changing a value" >}}

## All settings

| Setting | What it does | Default |
|---|---|---|
| **Auto-Tare Weight 1–5** | Weights of your cups or containers, in grams. Put one of them on the scale in the scale mode and it tares by itself. See [Weighing](../weighing/#auto-tare). | empty |
| **Auto-Tare Tolerance** | How close, in grams, a weight must be to a saved one to tare. | empty, which means 2 g |
| **Weight Averaging Threshold** | While the weight changes by less than this many grams per second, the scale averages more readings, so the display is calm. Raise it if the weight jumps around, lower it if the display reacts too slowly. | 1.0 |
| **Zero Tracking** | How far from zero, in grams, the empty scale still pulls itself back to zero. 0 turns it off. See [Weighing](../weighing/#zero-tracking). | 0.10 |
| **Shot Offset** | Seconds from the pump start to the first drop. A detected shot's timer starts that much earlier. See [Espresso](../espresso/#shot-offset). | 7.0 |
| **Lift-to-Tare** | How firmly you have to lift the platform to tare: **Off**, **Gentle**, **Normal**, **Firm**. See [Weighing](../weighing/#lift-to-tare). | Normal |
| **Shot Detection** | Whether the scale notices espresso shots by itself: **Off** or **On**. See [Espresso](../espresso/#shot-detection). | Off |
| **Wi-Fi** | Sets up Wi-Fi from your phone. See [Getting started](../getting-started/#setting-up-wi-fi). | |

{{< callout type="info" >}}
Shot Detection and Shot Offset apply as soon as you leave the settings. Weight Averaging Threshold, Zero Tracking and Lift-to-Tare apply the next time you switch the scale on.
{{< /callout >}}
