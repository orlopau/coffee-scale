Öffne **Einstellungen** in der Liste der Modi.

{{< screen name="settings_last" caption="Die letzten Einstellungen der Liste" >}}

- **Dreh** auf eine Einstellung und **klick**, um sie zu ändern.
- **Dreh**, um den Wert zu ändern, dann **klick**, um ihn zu speichern, oder **drück lange**, um ihn zu lassen, wie er war.
- **Langes Drücken** in der Liste verlässt die Einstellungen.

{{< screen name="settings_value_up" caption="Einen Wert ändern" >}}

## Alle Einstellungen

| Einstellung | Was sie tut | Standard |
|---|---|---|
| **Auto-Tare Gewicht 1–5** | Gewichte deiner Tassen oder Gefäße in Gramm. Stellst du eines davon im Waagen-Modus auf die Waage, tariert sie von selbst. Siehe [Wiegen](../weighing/#auto-tare). | leer |
| **Auto-Tare Toleranz** | Wie nah ein Gewicht in Gramm an einem gespeicherten liegen muss, damit sie tariert. | leer, das heißt 2 g |
| **Gewichts-Mittelung Schwellwert** | Solange sich das Gewicht um weniger als so viele Gramm pro Sekunde ändert, mittelt die Waage über mehr Messwerte, damit die Anzeige ruhig ist. Erhöhe ihn, wenn das Gewicht springt, senke ihn, wenn die Anzeige zu langsam reagiert. | 1,0 |
| **Nullpunkt-Nachführung** | Bis zu welchem Abstand von null in Gramm die leere Waage sich auf null zurückzieht. 0 schaltet es aus. Siehe [Wiegen](../weighing/#nullpunkt-nachführung). | 0,10 |
| **Shot-Vorlauf** | Sekunden vom Pumpenstart bis zum ersten Tropfen. Der Timer eines erkannten Shots startet um so viel früher. Siehe [Espresso](../espresso/#shot-vorlauf). | 7,0 |
| **Tara durch Anheben** | Wie fest du die Plattform anheben musst, um zu tarieren: **Aus**, **Sanft**, **Normal**, **Fest**. Siehe [Wiegen](../weighing/#tara-durch-anheben). | Normal |
| **Shot-Erkennung** | Ob die Waage Espresso-Shots von selbst bemerkt: **Aus** oder **An**. Siehe [Espresso](../espresso/#shot-erkennung). | Aus |
| **WLAN** | Richtet das WLAN vom Handy aus ein. Siehe [Erste Schritte](../getting-started/#wlan-einrichten). | |

{{< callout type="info" >}}
Shot-Erkennung und Shot-Vorlauf gelten, sobald du die Einstellungen verlässt. Gewichts-Mittelung Schwellwert, Nullpunkt-Nachführung und Tara durch Anheben gelten ab dem nächsten Einschalten.
{{< /callout >}}
